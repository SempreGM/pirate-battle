# Asset sources and licenses

The evaluator supplied the original `assets/` directory: ships, parts, terrain, effects, UI atlases, reference images, Jungle Gaming logo and WAV audio. `public/assets/` is a deployment copy of that directory. No generated imagery or external game art has been introduced.

The supplied package contains no license document or author attribution. Its provenance and permitted redistribution remain to be confirmed with the evaluator. No license is inferred from visual similarity to another asset pack.

The initial UI references Barlow / Barlow Condensed from Google Fonts with system fallback. These fonts are distributed under the SIL Open Font License by their upstream project: https://github.com/jpt/barlow. The application remains usable if external font loading fails.

Dependency licenses are included in the installed packages and recorded by the lockfile. MSW's generated service worker retains its license header.
